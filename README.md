## 📌 Repository Overview

This repository contains the complete practical coursework for **Programming with Python & Problem Solving (05MC0107)** as prescribed in the MCA Semester 1 curriculum at **Marwadi University**.

It features **50 lab practicals** covering fundamental computing logic, object-oriented programming (OOP), file operations, data analytics, visualization, and database integration with MySQL.
